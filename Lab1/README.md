# Python Lab 1

This folder contains the Python programs completed as part of Python Programming Lab 1.

## 1. Variable and Identifier Practice

### Aim
To declare variables of different data types and display their values and types.

### Logic
Declare variables for name, age, height and student status.
Use the `type()` function to display the data type of each variable.

### Sample Input
No input required.

### Sample Output

Name: Shubhi Type: <class 'str'>
Age: 20 Type: <class 'int'>
Height: 5.4 Type: <class 'float'>
Student: True Type: <class 'bool'>


## 2. Greeting Program

### Aim
To take the user's name, age and city as input and display a greeting.

### Logic
Take name, age and city from the user.
Use an f-string to combine the three values into one sentence.

### Sample Input

Enter your name: Shubhi
Enter your age: 20
Enter your city: Raipur

### Sample Output

Hello Shubhi! You are 20 years old and live in Raipur.


## 3. Arithmetic Operations

### Aim
To perform basic arithmetic operations on two numbers.

### Logic
Take two numbers as input.
Calculate their sum, difference, product, quotient and remainder and display each result with a label.

### Sample Input

Enter first number: 20
Enter second number: 6

### Sample Output

Sum: 26
Difference: 14
Product: 120
Quotient: 3.3333333333333335
Remainder: 2


## 4. Celsius to Fahrenheit

### Aim
To convert temperature from Celsius to Fahrenheit.

### Logic
Take the temperature in Celsius as input.
Apply the formula F = (C * 9/5) + 32 and display the Fahrenheit value.

### Sample Input

Enter temperature in Celsius: 25

### Sample Output

Temperature in Fahrenheit: 77.0


## 5. String Manipulation

### Aim
To perform different string operations on a full name.

### Logic
Take a full name as input.
Use string methods to display the name in uppercase, lowercase and title case. Also reverse the string and find its length.

### Sample Input

Enter your full name: Shubhi Saxena

### Sample Output

Uppercase: SHUBHI SAXENA
Lowercase: shubhi saxena
Title Case: Shubhi Saxena
Reversed: anexaS ihbuhS
Length: 13


## 6. Escape Sequence Practice

### Aim
To display a simple receipt using escape sequences.

### Logic
Use `\t` to create spacing between item names and prices.
Use `\n` to display different parts of the receipt on separate lines.

### Sample Input

No input required.

### Sample Output

        SHOPPING RECEIPT
------------------------------
Item            Price
------------------------------
Notebook        50
Pen             20
Pencil          10
------------------------------
Total           80
