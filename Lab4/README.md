# Lab 4 – Star Pattern and Matrix Operations

## 1. Star Pattern

### Aim
To write a Python program that takes an integer n from the user and prints a star pattern using nested loops.

### Logic
The program takes the number of rows from the user.
Nested loops are used to print the required number of stars in each row.

### Sample Input
Enter number of rows: 5

### Sample Output
*
**
***
****
*****


## 2. Matrix Operations

### Aim
To write a Python program to input a 3 × 3 matrix and perform different matrix operations.

### Logic
The program stores the matrix using Python lists and uses loops to calculate the sum, diagonal sum, largest and smallest elements.
It also uses nested loops to display the transpose of the matrix.

### Sample Input
Enter row 1: 1 2 3
Enter row 2: 4 5 6
Enter row 3: 7 8 9

### Sample Output
Matrix:
1    2    3
4    5    6
7    8    9

Sum of all elements: 45
Sum of main diagonal: 15
Largest element: 9
Smallest element: 1

Transpose:
1    4    7
2    5    8
3    6    9
