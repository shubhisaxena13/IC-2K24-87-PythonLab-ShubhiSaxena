## 1. Armstrong Number

### Aim

To check whether a number is an Armstrong number and print all Armstrong numbers within a given range.

### Logic

The program counts the number of digits and calculates the sum of each digit raised to the power of the number of digits. The result is compared with the original number. A function is used to perform the Armstrong check.

### Sample Input / Output

```text
Enter a number: 153
153 is an Armstrong number.
Enter range start: 100
Enter range end: 500
Armstrong numbers in the range:
