# Lab 3 – Pattern Printing

## 1. Hollow Diamond Star Pattern

### Aim
To write a Python program that takes an odd number n from the user and prints a hollow diamond star pattern using nested loops and conditional statements.

### Logic
The program divides the diamond into upper and lower halves.
Nested loops are used to print spaces and stars, while conditional statements keep the diamond hollow.

### Sample Input
Enter an odd number: 7

### Sample Output
   *
  * *
 *   *
*     *
 *   *
  * *
   *


## 2. Butterfly Star Pattern

### Aim
To write a Python program that takes the number of rows n from the user and prints a butterfly star pattern using nested loops.

### Logic
The program prints the upper half and lower half of the butterfly separately.
Nested loops are used to print stars and spaces to create the required pattern.

### Sample Input
Enter number of rows: 5

### Sample Output
*        *
**      **
***    ***
****  ****
**********
****  ****
***    ***
**      **
*        *
